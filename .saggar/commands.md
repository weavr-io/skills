# Commands

This repository publishes Markdown skills maintained in docs-weavr-io. It has no local build, dev server, or validation script.

- Install published skills: `npx skills add weavr-io/skills` - Install from GitHub as documented in the README; this doesn't test local edits. #quick
- Check whitespace: `git diff --check` - Check unstaged changes for whitespace errors. #quick
- Review changes: `git diff` - Review unstaged changes.

## Layout

- Repository status: `git status --short --branch` - Show the branch and working tree, then leave the shell ready for editing. #primary
